Victoria II War Analyzer
========================

Como usar
---------
1. Descomprime esta carpeta completa en cualquier sitio, por ejemplo en
   C:\Program Files\Victoria II War Analyzer o en el escritorio.
2. Haz doble clic en VickyWarAnalyzer.exe.
3. En la pestana de ajustes elige el fichero de partida de Victoria II y,
   si quieres ver los nombres y las banderas de los mods, la carpeta de
   Victoria II y la de los mods. Pulsa "Read file".

No hace falta instalar Java: la carpeta jre incluye un Java 8 con JavaFX.

El programa crea un archivo llamado paths.txt junto al ejecutable para
recordar la ultima partida usada. Ese archivo es tuyo, no lo subas a ningun
sitio.

Notas
-----
* La carpeta jre se puede borrar si ya tienes un Java 8 con JavaFX en el PATH
  o en JAVA_HOME.
* El analizador solo lee el fichero de partida, nunca lo modifica.
